# Reaction Time Lab

A small HCI experiment built with React, Tailwind CSS, and HTML5 Canvas.

The app measures how fast and accurately you classify stimuli:

- Press A for alphabet characters
- Press D for digits

Each session runs through 10 trials with countdown, stimulus, instant feedback, and a final summary.

## Run locally

1. Install dependencies:

   npm install

2. Start development server:

   npm run dev

3. Open the local URL shown in the terminal.

## Controls

- Space bar: start a session
- A key or A button: alphabet response
- D key or D button: digit response

## What you see

- Countdown before each trial
- Random letter or digit stimulus
- Correct/Wrong feedback with reaction time
- End summary: average, fastest, slowest, accuracy, and total correct

This project is meant to be simple, readable, and useful for HCI coursework demos.
